# Klotz Racer

3D-Autorennspiel im Klötzchen-Look (Three.js). Einfach `index.html` im Browser öffnen.

- **Tastatur:** Pfeiltasten oder WASD, Leertaste = Drift, R = zurück zum Checkpoint, P/Esc = Pause
- **Touch:** Tasten unten auf dem Bildschirm
- Fahr durch alle 6 Checkpoints ins Ziel, sammel Münzen, weich Kisten, Wänden, Schiebern und Drehbalken aus.
