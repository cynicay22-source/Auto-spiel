# Turbo Ring

Realistisches 3D-Rennspiel (Three.js) – einfach `index.html` im Browser öffnen.

- 2 Runden gegen 3 Gegner auf einem Rundkurs mit Leitplanken, Tribüne und Startampel
- Shop mit Autos, Motorrädern und Roller (Kompakt GTI, Yamaha Aerox 50, Sportlimousine V8, Porsche 911 GT3, BMW S 1000 RR, Ferrari F8, Lamborghini Huracán, Kawasaki Ninja H2, Bugatti Chiron)
- Geld gibt es fürs Gewinnen: Platz 1 = 1.000 € + Zeitbonus (je schneller, desto mehr)
- Motorsound mit Gängen, Reifenquietschen, Fahrtwind, Turbo-Pfeifen
- **Tastatur:** Pfeiltasten/WASD, Leertaste = Drift, C = Kamera, R = zurück auf die Strecke, P/Esc = Pause
- **Touch:** Tasten unten auf dem Bildschirm

Spielstand und Geld werden im Browser gespeichert.
